# A-Frame 2台共有駅オブジェクト / 動作確認用

## 1. インストール
VS Code でこのフォルダを開き、ターミナルから実行します。

```powershell
npm init -y
npm install express socket.io
node server.js
```

サーバーPC: `http://localhost:8080`
別のPC: `http://<サーバーPCのIPv4アドレス>:8080`

両方同じWi-Fi/LANに接続してください。接続不可なら Windows ファイアウォールの許可と TCP 8080 ポートを確認してください。
すでに `npx http-server . -p 8080` が動いていれば停止してください。

## 2. サンプルの使い方
両PCで開きます。駅の箱を左クリックで2秒長押しし、そのままドラッグします。
移動が相手の画面にも反映されます。別の人が押しても、操作権が使用中なら移動できません。
WASDで移動すると相手の簡易アバターの位置も同期されます。

## 3. 既存の都市VRへ組み込む
このサンプルの `public/index.html` は動作確認用です。既存の index.html を置き換える場合はバックアップしてください。

- 既存の `index.html`、各JS、`models/`、テクスチャなどの相対フォルダ構成を保ちながら `public/` に配置。
- 既存 `index.html` の A-Frame 読み込みの後、`<head>` 内へ以下を追加。

```html
<script src="/socket.io/socket.io.js"></script>
<script src="multiplayer.js"></script>
<script src="station-grab.js"></script>
```

- 既存の駅のルートエンティティに、全PCで同じ `id="station"` と `station-grab` を指定。
- 既存の `station-grab` コンポーネントの定義は**二重に読み込まない**。
- 既存の `partner-avatar`（静止アバター）があると見た目が重複するため、必要に応じて無効化。
- 同じ駅を操作する別のAIスクリプトがある場合は一度無効に。
- サンプルはPCブラウザでのマウス操作対応。VRコントローラーでの掴み操作は別実装が必要。
- カメラは通常の `<a-camera>` あるいは camera コンポーネントを使用。

## 4. 仕様・制限
- 駅の移動はワールド直下のエンティティ（親に回転・拡大縮小がかかっていない）を想定。x,z 軸に水平移動。
- サーバーのメモリで駅の位置と操作権を管理。再起動すると状態はリセット。
- ネットワーク遅延のため、位置同期は完全に同時ではありません。
- 本実装では操作権を押下開始から取得し、その取得が成功してから2秒カウントします。
- このサンプルはLAN内プロトタイプ用。インターネット公開には認証、HTTPS、適切なアクセス制御が必要。
